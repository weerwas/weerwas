## S-Curve Generator for Construction Projects

This repository includes a simple Python utility to plot an S-curve comparing planned vs. actual progress and cumulative resources over time.

### Usage

1. Install dependencies:
   ```bash
   pip install pandas matplotlib
   ```
2. Run the script with a CSV file containing `Date`, `Planned`, `Actual`, and `Resource` columns:
   ```bash
   python s_curve.py data/sample_progress.csv
   ```
   The chart will be saved as `s_curve.png`.

The repository contains `data/sample_progress.csv` as an example dataset.
